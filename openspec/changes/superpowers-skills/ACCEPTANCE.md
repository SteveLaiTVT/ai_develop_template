# Acceptance Criteria: Superpowers & Skills

- Spec is approved with clear scope, goals, and milestone plan (M0-M4) covering registry, sandbox, invocation, UI entrypoints, and risk register.
- Manifest schema v1 documented with sample manifest; validation rules defined.
- Default sandbox strategy chosen and justified; resource limit policies recorded.
- Permission scope taxonomy and approval workflow defined for registration and invocation.
- End-to-end reference path documented: register skill → approval → invoke via orchestrator → capture logs/metrics/audit.
- UI trigger plan outlined for command palette/launcher and inline actions with expected UX states.
- Risk log includes mitigation for sandbox safety, performance, registry consistency, UX discoverability, and observability gaps.
- Open questions captured with owners and decision paths for runtime choice, network policy, audit requirements, and first UI entrypoint.
